# Small Business IT Infrastructure Lab

## Overview

This project is a hands-on IT infrastructure lab designed to apply and strengthen my skills in Linux System Administration, Networking, and IT Infrastructure.

The goal is to build and document a small-business environment using practical configuration, testing, troubleshooting, and recovery exercises.

## Objectives

- Practice Linux server administration using Red Hat Enterprise Linux 9.
- Understand server networking, IP configuration, and routing.
- Manage users, groups, permissions, and access control.
- Configure and troubleshoot essential infrastructure services.
- Practice monitoring, backup, and recovery procedures.
- Document technical findings and troubleshooting steps.

## Lab Environment

| Component | Details |
|---|---|
| Server OS | Red Hat Enterprise Linux 9 |
| Virtualization | Oracle VirtualBox |
| Client | Windows 10 |
| Network Mode | Bridged Adapter |
